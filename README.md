# Checks, Captures, Threats

Chess lessons, puzzles and a sparring bot with a blunder check. Static site, no build step.

- Run: `npm start`, then open http://localhost:8080
- Test: `npm test`
- Deploy: publish the `site/` folder to any HTTPS static host
- Install on iPhone: open the URL in Safari, Share, Add to Home Screen

Working notes for Claude Code are in `CLAUDE.md`.

Credits: rules and notation by chess.js (BSD). The "Classic" piece set is by Colin M.L. Burnett (GPLv2+), via Lichess.
